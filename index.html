Engine Capabilities

Built for accurate market measurement

StackCheck ignores promotional keywords and analyzes requirement depth, compensation brackets, and multi-skill pairings.

Live Job Ingestion

Queries HiringCafe directly for active postings. Filter by country, remote policy, and role keyword without relying on stale static datasets.

Section-Aware Weighting

Applies a 1.8 multiplier to hard requirements and qualifications, while casual mentions in overviews receive standard 1.0 weight.

Skill Co-Occurrence

Reveals which technologies appear together in the same listing, identifying common combinations such as Python with Snowflake or React with TypeScript.

Normalized Compensation

Standardizes hourly, monthly, and yearly wage disclosures into annual USD brackets with 25th, median, and 75th percentile marks.

Zero-Install Runtime

Ships as a standalone binary for Linux, macOS, and Windows. Run checks without setting up a local database or virtual environment.

Structured Data Exports

Export query outputs directly to stdout, markdown tables, CSV files, or clean JSON objects for automated pipelines and dashboards.

Data Pipeline

Four stages from raw text to market metrics

How StackCheck transforms unstructured job postings into verified skill demand.

STEP 01

Ingest

Queries the job search API, retrieves active postings matching your search filters, and caches responses locally.

STEP 02

Segment

Identifies document boundaries, separating role overviews, mandatory qualifications, and benefit summaries.

STEP 03

Weight

Matches skills against an alias dictionary and calculates weighted scores based on section priority.

STEP 04

Report

Generates terminal summaries, co-occurrence correlation scores, and interquartile compensation spreads.

Installation

Get started in seconds

Choose your platform below to install the StackCheck binary or run directly with Python.

curl -fsSL https://raw.githubusercontent.com/haydermuhib/StackCheck/main/install.sh | bash

Installs the standalone binary to ~/.local/bin/stackcheck. No Python runtime required.

irm https://raw.githubusercontent.com/haydermuhib/StackCheck/main/install.ps1 | iex

Downloads the Windows executable and places it in your user PATH.

pip install git+https://github.com/haydermuhib/StackCheck.git

Requires Python 3.10 or later. Works within existing virtual environments.

docker run --rm -it ghcr.io/haydermuhib/stackcheck query "backend"

Runs within an isolated lightweight container.
